# M4 首页与个性化推荐 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans。步骤为 checkbox。

**Goal:** 首页 = 豆瓣标签流：电影/剧集切换 + 标签 chips + 海报网格无限滚动 + 首位「为你推荐」chip（基于观看历史映射标签，历史≥2 条才出现）。点击卡片以片名发起聚合搜索。

**已核实契约（线上实测 2026-10-28）：**
- `GET /api/douban/tags?type=movie|tv` → `{tags:["热门","最新","豆瓣高分","冷门佳片","华语","欧美","韩国","日本"]}`
- `GET /api/douban/recommend?tag=&type=&page_limit=20&page_start=N` → `{subjects:[{id,title,cover,rate,playable,url,...}]}`；`cover` 为站点相对路径（`/api/douban/image?url=…`），App 拼 `base+cover`
- 站点无按标题查豆瓣的接口 → 详情页豆瓣卡不做（详情已有导演/主演/简介）

**Architecture:** `DoubanRepository`（OkHttp + 序列化，含相对封面 URL 解析）；`RecommendTagMapper`（纯函数：历史 type_name → 豆瓣标签，TDD）；`HomeViewModel`（标签流分页 StateFlow + 历史驱动推荐位）；`HomeScreen`（TopTabRow 电影/剧集 + LazyVerticalGrid + 无限滚动）。

## Global Constraints

沿用 M0-M3。分页 page_limit=20；封面加载失败显示占位底色不崩布局；「为你推荐」不足 2 条历史不显示。
