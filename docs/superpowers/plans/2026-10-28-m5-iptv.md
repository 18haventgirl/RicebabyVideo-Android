# M5 IPTV 直播 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans。

**Goal:** 直播页 = 原生频道分组列表（M3U 解析）+ 搜索 + 点击频道进入全屏 HLS 播放。

**契约（实测 2026-10-28）：** 站点 `GET /api/auth` 的 `iptvSources` 给出 M3U 地址（逗号分隔多源）；M3U 为标准 `#EXTINF:-1 tvg-name tvg-logo group-title="组",显示名` + url 行；频道流多为运营商 IPv6 内网地址，**播放与列表拉取都必须走站点代理**：列表 `GET {base}/api/proxy?url=<m3u地址>`，流 `GET {base}/api/iptv/stream?url=<频道地址>`（站点已处理 UA/Referer/HEVC 降级/子路径重写）。

**架构决策（偏离 spec §2 一处）：** IPTV 播放用 Media3 ExoPlayer（1.11.0）而非 WebView——站点 `/player` 页只接受 CMS id+source 流程，无法承载直连流地址；ExoPlayer 直接消费站点 stream 代理输出，体验更好。此决策记录进 spec 已知偏差。

## Global Constraints

沿用 M0-M4。频道数可达数百，列表必须 Lazy + 分组折叠；播放页退出必须 release Player；搜索防抖 300ms。
