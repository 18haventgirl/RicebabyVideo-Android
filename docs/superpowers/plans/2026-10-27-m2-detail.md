# M2 详情页与线路剧集 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 点击搜索结果/收藏进入详情页：完整影片信息、同名线路切换、剧集网格；点击剧集暂以提示收尾（播放器 M3 接入）。

**Architecture:** `DetailClient` 调 `POST /api/detail`（body `{id, source:{id,name,baseUrl,...}}`，契约已从 `lib/api/detail-api.ts` 核实：返回 `{success, data:{vod_*字段, episodes:[{name,url}], source, source_code}}`）；「线路」= 同名视频在不同源的结果集合，由搜索页打包（含被点项）经 `DetailRegistry`（内存单例）+ 紧凑 JSON 导航参数双轨传递（进程重建后 Registry 丢失时降级用参数中的最小集）；待看页收藏无同名集合，线路列表退化为单条。

**Tech Stack:** M1 基础，无新增依赖。

**Spec:** `docs/superpowers/specs/2026-10-26-ricebabyvideo-android-design.md` §4（详情页）

## Global Constraints

沿用 M0/M1 全部约束。新增：剧集 URL 绝不写入导航参数（长度与隐私），只传元数据；`vod_content` 展示前去 HTML 标签。
